# UV Island Normalizer

UVアイランドのサイズを3D空間基準で統一するBlenderアドオンです。

---

## 概要

基準となるUVアイランドを登録し、他のアイランドのテクセル密度（解像度）を自動で揃えます。  
「あとから追加したメッシュのUVを、既存のメッシュと完全に同じ比率に調整したい」という用途に最適です。

---

## 動作確認バージョン

- **Blender 3.6**（メインターゲット）
- **Blender 4.2 〜 5.1**（Extension形式に対応済み）

---

## インストール方法

### Blender 3.6 〜 4.1 の場合

1. Blenderを起動する
2. **Edit > Preferences > Add-ons** を開く
3. 右上の **Install** ボタンをクリック
4. ZIPファイルを選択して **Install Add-on** をクリック
5. 一覧の **UV: UV Island Normalizer** をオンにする

### Blender 4.2 以降（5.x を含む）の場合

1. Blenderを起動する
2. **Edit > Preferences** を開く
3. 左側の **Get Extensions** タブを選択
4. 右上の **▼（ドロップダウン）** をクリック
5. **Install from Disk** を選択
6. ZIPファイルを選択してインストール（自動で有効化されます）

---

## 使い方

### 事前準備

1. UVを編集したいメッシュオブジェクトを選択する
2. **Tab キー** で編集モードに入る
3. UVエディターを開く
4. UVエディター左上の **UV同期選択（↔アイコン）をオフ** にする
5. UVエディターの右側サイドバー（**N キー**で表示）を開き、**「UV Island Normalizer」タブ** を選択する

### 実行手順

**Step 1 — 基準アイランドを登録する**

1. 基準にしたいアイランドを1つだけ選択する
2. **「① 基準に設定」** ボタンを押す
3. パネルに「基準: ○○フェース設定済み ✓」と表示されれば登録完了

**Step 2 — サイズを統一する**

4. 揃えたいアイランドを選択する（基準アイランドを含めて選択してもよい）
5. **「② アイランドサイズを統一」** ボタンを押す

### 結果

基準アイランドのテクセル密度（UV面積 ÷ 3D面積の比率）に合わせて、  
対象アイランドが自動的にスケールされます。各アイランドの位置は変わりません。

---

## 各部の説明

### UV同期選択とは

UVエディターと3Dビューポートの選択を連動させる機能です。  
**このアドオンを使う際はオフにしてください。**

### 基準のリセット

パネルの「基準: ○○フェース設定済み ✓」の右にある **×ボタン** を押すとリセットできます。  
基準が未設定の状態では「② アイランドサイズを統一」ボタンはグレーアウトして押せません。

---

## 注意事項

- 基準アイランドを登録する際は、1つのアイランドだけ選択してください
- 3D面積またはUV面積がゼロのアイランドはスキップされます
- 基準アイランドはオブジェクトごとに保持されますが、Blenderを再起動するとリセットされます
- 実行後は **Ctrl+Z** で元に戻せます
